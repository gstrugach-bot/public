# Greg Strugach WordPress Theme

A custom Bootstrap-powered WordPress theme.

## Installation
1. Copy `greg-strugach` folder into `wp-content/themes/`.
2. Activate in WP Admin → Appearance → Themes.
3. Assign menus under Appearance → Menus.

## Bootstrap
- Loaded via CDN in `functions.php`.

## Development
- Edit templates and assets in `assets/css/theme.css` and `assets/js/main.js`.
- Use Git for version control.

## Deployment
- Zip the theme folder and upload via WP Admin → Themes → Add New → Upload Theme.
